# Ejemplos para copiar

- **[mi-negocio/](mi-negocio/)**: la carpeta del escalón 300, lista para la app de Claude. Copia la carpeta, cambia lo que está entre corchetes en `CLAUDE.md` y `00-contexto/`, y pon tus archivos en `03-entradas/`.
- **[mi-proyecto/](mi-proyecto/)**: lo que Claude Code lee solo en un proyecto de software: `CLAUDE.md`, y la carpeta oculta `.claude/` con permisos (`settings.json`), reglas, una skill y un subagente revisor.

En el Finder, `⌘ ⇧ .` muestra las carpetas ocultas como `.claude/`.
