# Plantilla · Petición en 4 partes

```
Objetivo: [qué quieres y para quién].

Contexto: [lo que Claude necesita ver: archivos, datos, lo que pidió el cliente]. Tono: [cercano / formal].

Está listo cuando: [cómo se comprueba: qué contiene, en cuántas páginas, qué prueba pasa].

Límites:
- No inventes [precios / fechas / nombres]: si no está en [archivo], dilo.
- No prometas [fechas / descuentos] no escritos.
- No toques [lo que no se cambia].
- Si te falta un dato, pregúntamelo antes de suponer.
```

## Ejemplo

```
Objetivo: una cotización para Acme de mantenimiento mensual, lista para enviar hoy.
Contexto: la lista de precios está en 00-contexto/precios.md. Acme pidió 3 equipos. Tono: formal.
Está listo cuando: tiene alcance, precio con IVA, vigencia y forma de pago, en una página.
Límites:
- No inventes precios: si no está en la lista, dilo.
- No prometas fechas ni descuentos no escritos.
- Si te falta un dato, pregúntamelo antes de suponer.
```
